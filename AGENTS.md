## antislop
For UI, copy, people, mobile layout, or code comments work, load the antislop skill for the task:
- Core filter, always on: `antislop`
- UI / visual: `antislop-ui`
- Copy & text: `antislop-copywriting`
- People: `antislop-human`
- Mobile / responsive: `antislop-layoutmobile`
- Code comments: `antislop-code`
Before starting, ask the user when antislop applies: during the work, or after it is done.
<!-- antislop:end -->

## Design skills

- `impeccable` — design engine. Drive it per task: `/impeccable shape`, `audit`, `critique`, `polish`, `animate`, `layout`, `typeset`, `live`, `init`. It runs `<skill>/scripts/impeccable context` once per session, and the first run downloads the engine binary into `~/.impeccable/bin/` (checksum-verified from the project's GitHub release).
- `hallmark` — design ruleset for greenfield pages, redesigns, and audits: macrostructure, theme, typography, motion, slop test. Invoke by name with a brief, or leave it to attach by description.
